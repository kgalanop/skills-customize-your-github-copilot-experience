# 📘 Assignment: Introduction to Algorithms

## 🎯 Objective

Implement basic sorting and searching algorithms in Python to understand fundamental algorithmic concepts and their practical applications.

## 📝 Tasks

### 🛠️ Implement Bubble Sort

#### Description
Write a function that sorts a list of numbers using the bubble sort algorithm.

#### Requirements
Completed program should:

- Define a function `bubble_sort(arr)` that takes a list of numbers.
- Sort the list in ascending order using bubble sort.
- Return the sorted list.
- Example usage:
  ```python
  print(bubble_sort([64, 34, 25, 12, 22, 11, 90]))  # [11, 12, 22, 25, 34, 64, 90]
  ```

### 🛠️ Implement Linear Search

#### Description
Write a function that searches for a target value in a list using linear search.

#### Requirements
Completed program should:

- Define a function `linear_search(arr, target)` that takes a list and a target value.
- Return the index of the target if found, or -1 if not found.
- Example usage:
  ```python
  print(linear_search([10, 20, 30, 40], 30))  # 2
  print(linear_search([10, 20, 30, 40], 50))  # -1
  ```
