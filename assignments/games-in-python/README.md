
# 📘 Assignment: Games in Python

## 🎯 Objective

Practice Python programming by building a Hangman-style word guessing game that uses strings, loops, conditionals, and random selection.

## 📝 Tasks

### 🛠️ Build the Hangman Game

#### Description
Create a text-based Hangman game where the player guesses letters to reveal a hidden word before running out of attempts.

#### Requirements
Completed program should:

- Randomly select a word from a predefined list
- Accept one letter guess at a time from the player
- Show the current progress with blanks and revealed letters
- Track incorrect guesses and remaining attempts
- End when the word is fully guessed or the player runs out of attempts
- Display a win or lose message and reveal the correct word

### 🛠️ Add Replay and Input Validation

#### Description
Improve the game by letting the player play again easily and validating the letter guesses.

#### Requirements
Completed program should:

- Ask the player if they want to play again after each game
- Ignore invalid input such as numbers, multiple letters, or empty entries
- Prevent repeated guesses from counting against the player
- Keep the game flow clear with updated prompts and messages
